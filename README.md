# Algebraic Calculator

A cross-platform desktop application designed to evaluate algebraic expressions and perform mathematical operations through a clean, intuitive graphical interface.

## About The Project

This project was developed as a personal study project to deepen knowledge and practical skills in C++ programming and the Qt Framework.

The main goal of the Algebraic Calculator is to provide an easy-to-use desktop tool capable of parsing, simplifying, and evaluating algebraic mathematical expressions seamlessly in real time.
